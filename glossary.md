# Glossary

This glossary provides definitions for key terms used in this repository. Terms are structured following the SKOS (Simple Knowledge Organization System) process, ensuring clarity, consistency, and interoperability with external vocabularies.

## How to Contribute
- If you would like to propose a new term or update an existing one, please follow the SKOS process.
- Each term should include a preferred label, alternative labels (if applicable), a definition, and links to related concepts.
- Submit changes via pull requests or discuss proposed modifications in the issues section.

## SKOS Principles
- **Preferred Labels (`skos:prefLabel`)**: The primary label used to refer to a term.
- **Alternative Labels (`skos:altLabel`)**: Other commonly used terms or synonyms.
- **Definitions (`skos:definition`)**: A precise explanation of the term.
- **Broader/Narrower Concepts (`skos:broader`, `skos:narrower`)**: Relationships indicating hierarchy.
- **Related Concepts (`skos:related`)**: Links to other relevant terms.

For further details on SKOS, refer to the [W3C SKOS documentation](https://www.w3.org/2004/02/skos/).
